# Fortnite Sprite Checklist Ver.12.0.0

Fortnite のスプライト／精霊の取得状況を確認するためのチェックリストです。日本語・英語の表示に対応し、チェック状況や表示設定をブラウザー内に保存します。

## 公開ページ

- **Webサイト:** https://mylifereading6666-oss.github.io/fortnite-sprite-checklist/
- **このリポジトリ:** https://github.com/mylifereading6666-oss/fortnite-sprite-checklist
- **参考・原作プロジェクト:** [SC-BCH/fortnite-sprite-checklist](https://github.com/SC-BCH/fortnite-sprite-checklist)

## 使い方

1. 上の公開ページを開きます。
2. 画面上部のバージョンタブから、利用したいチェックリストを選びます。
3. 各項目を操作して、取得状況を記録します。
4. 必要に応じて「言語」から日本語／Englishを切り替えます。
5. 「画像保存」で現在のチェックリスト画像を保存できます。対応環境では「画像コピー」も利用できます。
6. 名前設定、取得マークなどの表示設定は、画面内の設定パネルから変更できます。

### 保存について

チェック状態や一部の設定は、ブラウザーのローカルストレージに保存されます。通常は同じブラウザー・同じ端末でページを再度開くと引き継がれます。別の端末やブラウザーへの自動同期、アカウントによるクラウド保存はありません。ブラウザーのデータを消去すると、保存内容が失われる場合があります。

### 画像が表示されない場合

- ページを再読み込みしてください。
- GitHub Pages のデプロイが完了しているか、[Actions](https://github.com/mylifereading6666-oss/fortnite-sprite-checklist/actions) で確認してください。
- 画像ファイルへのURLが404になる場合は、公開先にファイルが配置されているか確認してください。
